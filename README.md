# AI Portfolio Website Generator 🚀

An AI-powered application that generates a complete portfolio website
(HTML, CSS, JS) from a resume using a two-stage LLM pipeline.

## Tech Stack
- Streamlit
- LangChain
- Google Gemini API
- PyPDF2
- python-docx

## Features
- Resume upload (PDF/DOCX)
- AI resume screening
- Automatic website generation
- Live preview
- Downloadable ZIP

## Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
